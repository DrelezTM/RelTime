## Installation 📑
* Clone Repository
  ```sh
  git clone https://github.com/DrelezTM/RelTime.git
  ```
* Open Directory
  ```sh
  cd RelTime
  ```
* Install Dependencies
  ```sh
  npm install
  ```
* Start Project
  ```sh
  npm run dev
  ```
* Build for Production
  ```sh
  npm run build
  ```

## Features ✨
* 🗺️ Peta interaktif berbasis MapLibre GL dengan layer Streets & Satelit
* 🚆 Pelacakan posisi kereta realtime (Commuter Line & Kereta Jarak Jauh)
* 🕒 Jadwal keberangkatan & kedatangan kereta di setiap stasiun (Live Timetable)
* 📍 Detail rute kereta lengkap dengan estimasi waktu tiba (ETA) dan indikator stasiun (Stepper)
* 🔍 Pencarian cerdas (Smart Search Bar) untuk stasiun dan nomor/nama kereta
* 🎛️ Filter kategori terpadu (Stasiun, Commuter Line, Kereta Jarak Jauh, Kereta Berjalan)
* 🧭 Deteksi posisi pengguna (Geolocation) langsung di atas peta
* ⚡ Navigasi cepat dari penanda peta ke detail jadwal dan informasi kereta
